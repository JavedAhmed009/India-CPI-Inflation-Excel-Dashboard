# India-CPI-Inflation-Excel-Dashboard
Excel dashboard analysing India’s CPI inflation (2013-2023) on 10,000+ cleaned records using pivot tables and charts. Findings: Food &amp; Beverages drives 47.8% of CPI, inflation peaked at 6.52% in 2020, Spices rose most (+27.6 pts), Health saw the biggest post-COVID MoM rise, and Transportation correlates most with fuel prices (+0.67).
